## 🧭 Thesis Workflow

My M.Sc. thesis focused on automatic registration of preoperative and intraoperative views for AR-guided endonasal surgery.

```mermaid
flowchart LR
    A[Preoperative CT-based Anatomy] --> B[3D Anatomical Model]
    C[Intraoperative Surgical View / Mesh] --> D[Semantic Scene Understanding]
    B --> E[Coarse Semantic Initialization]
    D --> E
    E --> F[Rigid Geometric Refinement]
    F --> G[Registered View for AR Guidance]
````

This workflow combines **semantic initialization** with **rigid geometric refinement** to align preoperative anatomical structures with intraoperative surgical data while avoiding the need to display sensitive patient imagery.
