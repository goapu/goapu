## ⚙️ Engineering Principles

I focus on building systems that are:

* **Geometrically rigorous** — transformations, coordinate systems, assumptions, and error metrics are explicitly defined.
* **Quantitatively evaluated** — performance is measured using reproducible spatial and machine-learning metrics.
* **Robust to real-world data** — pipelines account for noise, partial observations, missing data, confidence values, and interrupted processing.
* **Modular and deployable** — research components are structured as maintainable applications, APIs, and automated workflows.
* **Reproducible** — experiments include validated inputs, configuration tracking, diagnostic outputs, and audit-ready results.
